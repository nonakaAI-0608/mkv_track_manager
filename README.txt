MKV トラック管理 v1.4.1
====================
指定フォルダのMKVから、選択した字幕・音声・映像トラックを削除し、
同じファイル名に置き換えるWindows向けGUIです。

【必要なもの】
・Windows 10 / 11
・Python 3.10以降（python.org版。インストール時にTcl/Tkとランチャーを含める）
  https://www.python.org/downloads/windows/
・MKVToolNix（mkvmerge.exe。インストール済みのものを利用できます）
  https://mkvtoolnix.download/downloads.html#windows
ドラッグ＆ドロップにはtkinterdnd2を使用します。start.batの初回起動時に
アプリ内のvendorフォルダへ自動導入します（初回のみインターネット接続が必要）。
導入に失敗した場合も、参照／ファイルを追加ボタンで読み込めます。実行ファイルを同梱した単体EXE版ではありません。

【起動】
ZIPをすべて展開し、start.batをダブルクリック。
mkvmergeが自動で見つからない場合は、上段の「参照」でmkvmerge.exeを指定。
通常は C:\Program Files\MKVToolNix\mkvmerge.exe です。
mkvtoolnix-gui.exeではなくmkvmerge.exeを選んでください。

【フォルダ内の字幕をまとめて削除】
1. 対象フォルダを選択し「読み込み」を押します。
2. 「全ファイルを選択」を押します。
3. 「選択行の字幕を全削除」を押します。
4. 一覧の「削除予定」を確認します。
5. バックアップが必要な場合だけ「元ファイルを .mkv.bak で残す」にチェックします。
6. 「変更内容を確認して上書き実行」を押し、確認画面で実行します。
初期状態は全トラック保持です。読み込むだけでは字幕を削除しません。
変更がないファイルは処理をスキップします。

【個別のトラック管理】
・ファイルを1つ選ぶと、下段にトラックID・形式・言語・名前・既定／強制フラグを表示。
・「残す」のチェックをクリック、またはトラックを選んでスペースキーで切替。
・チェックがあるトラックを保持し、チェックがないトラックを削除します。
・字幕だけでなく、音声・映像も個別に選択できます。
・「選択行の日本語以外音声を削除」「指定言語の音声だけ残す」を複数ファイルへ適用できます。
・言語指定はja/jpn、en/eng等に対応。ja-JP等は基本言語で照合します。
  指定言語の音声がないファイルは設定を変更しません。
・名前・言語・既定／強制フラグは表示のみ。編集、並べ替え、別ファイルからの追加は未対応。
・チャプター、添付フォントなどは削除指定せず引き継ぎます。
・全トラックの削除は不可。映像だけ／音声だけ残す操作は可能です。

【選択行と処理対象の違い】
青く選択した行：一括設定ボタンの適用先。Ctrl/Shiftで複数選択可能。
左端「対象」のチェック：実行時に処理するファイル。
初期状態は解析に成功した全ファイルが処理対象です。
青い選択を外しても、設定した削除予定は残ります。
処理しないファイルは「対象」チェックを外してください。

【上書きの仕組み】
mkvmergeで選択した圧縮トラックを再多重化します。再エンコードは行いません。
映像・音声の品質を落としませんが、コンテナの構造や一部の管理情報、
ファイルサイズ、更新日時は変わることがあります。ファイル全体のバイト一致ではありません。

元ファイルと同じフォルダに作業ディレクトリを作り、そこに一時出力します。
終了コード0、出力のトラック種別・コーデックID・UID、添付情報、チャプター数を
確認し、同一ファイルシステム内の置き換え操作で元パスを更新します。
この検証は全フレームをデコードしたり全データの一致を保証するものではありません。
エラー、警告、検証不一致の場合は置き換えません。

作業中は元ファイルサイズ＋16MB以上の空き容量が必要です。
これは事前判定の目安で、出力サイズや同時利用により追加容量が必要な場合があります。
他アプリでの録画・編集・同期が進行中のファイルは対象にしないでください。
解析時と置換前にファイル状態を確認し、変更を検出した場合は停止します。
ファイルが使用中で置き換えに失敗した場合も元ファイルは保持されます。

バックアップあり（チェックをオンにした場合）：
  例：movie.mkv の元データを movie.mkv.bak に保持。
  同名バックアップがある場合は上書きせず、そのファイルの処理を中止します。
  対応するファイルシステムではハードリンクを使い、非対応ならコピーします。
  コピーの場合はバックアップ分の追加空き容量が必要です。
  復元する場合はアプリを終了し、新しいmovie.mkvを別の名前へ移してから、
  movie.mkv.bakをmovie.mkvへ名前変更してください。
バックアップなし（初期設定）：
  処理成功後に元データは残りません。削除したトラックは戻せません。

「中止」は処理中の外部プロセスを停止し、置換前のファイルを保持します。
すでに完了したファイルは元に戻りません。
置換操作が始まった後の中止は次のファイルから反映される場合があります。
停電や強制終了など、OS・ストレージ側の障害による破損を保証するものではありません。
強制終了後に残る .mkv-track-work-* フォルダは、アプリ終了と元ファイルの確認後に
削除できます。通常の読み込みでは作業ディレクトリを除外します。

【字幕が見つからない場合】
人間向けの文字列表示ではなく、mkvmerge -J のJSONで字幕トラックを認識します。
字幕形式が対応していれば、SRT、ASS、PGS等の画像字幕も対象になります。
映像に直接焼き込まれた字幕は独立トラックではないため、本ツールでは削除できません。
外部の.srt/.assファイルは変更しません。
解析失敗時は画面下のログを確認してください。

【検証範囲】
Pythonの構文確認と、自動テスト22件（模擬したmkvmerge出力による
置換成功、警告時の保持、検証失敗、入力変更、キャンセル、既存バックアップ保護、
置換失敗など）を実施。
作成環境ではWindows GUI・ドラッグ＆ドロップの実操作、および実際のmkvmergeによる動画処理は未検証です。
最初はコピーした短いMKVで、字幕削除と映像・音声の再生を確認してください。
開発用テスト：python -m unittest -v

【v1.1で追加・修正】
・Windowsで上書き前に [Errno 9] Bad file descriptor となる問題を修正。
  出力のディスク書き込み確定を、読み書き可能なハンドルで行うよう変更。
・字幕を指定言語だけに絞る機能を追加。
  「全ファイルを選択」→残す言語「ja」→「選択行でこの言語の字幕だけ残す」。
  日本語字幕がないファイルは変更しません。言語未設定の字幕は日本語と推測しません。
  日本語字幕があるファイルでは、日本語以外・言語未設定の字幕を削除予定にします。
  焼き込み字幕は対象外です。
・フォルダ／複数MKVファイルを一覧にドラッグ＆ドロップして読み込み。
  v1.2では既存の一覧・トラック選択をリセットして入れ替えます。
  フォルダ内の下位フォルダは「サブフォルダも対象」がオンの場合のみ読み込み。
  「ファイルを追加…」ボタンからも複数ファイルを選択できます。
  「読み込み」は従来どおり、確認後に一覧を入れ替えます。
・Ctrl/Shiftで複数行選択後、選択行の左端のチェック欄をクリックすると一括切替。
  Spaceキー、右クリックメニューでも一括切替できます。
・「ログを別ウィンドウで開く」「ログをすべてコピー」「ログを保存…」を追加。
  失敗した場合は読み込み／処理終了時にログを自動表示。
  失敗行をダブルクリックしてもログを表示します。
  ログは %LOCALAPPDATA%\MKVTrackManager\logs にも自動保存します。
  相談時には「ログをすべてコピー」を押して貼り付けてください。

ドラッグ＆ドロップ実装の参照：
https://github.com/Eliav2/tkinterdnd2

【v1.2で変更】
・ドラッグ＆ドロップ時は確認ダイアログなしでリストを入れ替えます。
  前の一覧の削除予定・チェック状態はリセットします。実ファイルは変更しません。
・対象フォルダ欄は、フォルダのドロップならそのフォルダ、
  MKVファイルならその保存先フォルダへ更新します。
  複数フォルダの場合は「 | 」区切りで表示し、同じフォルダは重複表示しません。
  ドロップ時に読み込むのはドロップしたファイル／フォルダです。
  「読み込み」ボタンでは表示したフォルダ内のMKVを再読み込みします。
  処理中・無効なファイルのドロップでは一覧を入れ替えません。
  「ファイルを追加…」ボタンは引き続き追加用です。
・画面下部にログ専用領域を確保し、初期サイズでもログを表示します。
・読み込み・上書き処理の件数とファイル名をログにも記録します。
  各ファイルの処理開始・完了・失敗を確認できます。
・経過時間をHH:MM:SS形式で常時表示。読み込み／上書き開始ごとにリセットし、
  完了・中止後はその時間で停止します。ログにも時刻と経過時間を付けます。
・バックアップは引き続き初期値オフです。

v1.2検証：構文確認と自動テスト22件が通過。
Windows実機のレイアウト・ドラッグ＆ドロップ実操作は作成環境では未検証です。

【v1.3で変更】
一覧直下のボタンを次の順に整理しました。
[全ファイルを選択] [選択行の字幕を全削除]
[選択行の日本語以外音声を削除] [選択行の設定を元に戻す]
・チェックを付ける／外すボタン、先頭音声だけ残すボタンを削除。
・複数選択後、「対象」欄をクリックして一括でチェックを付ける／外す操作は維持。
・Ctrl+Aでも一覧の全ファイルを選択できます。チェック状態は変えません。
  入力欄やログ内では、その欄の文字を選ぶ通常のCtrl+A動作を優先します。
・日本語音声ボタンは、選択行に対して言語jaを指定した音声保持と同じ処理を行います。
  「残す言語」欄の入力値は変更しません。日本語音声がないファイルは変更しません。

【v1.3.1 添付ファイルの診断ログ】
「添付ファイルの検証に失敗しました」の詳細を表示する診断更新です。
処理前後の添付個数、変化した名前・MIMEタイプ・サイズ・同一情報の個数を記録します。
MIMEタイプだけの変化か、名前・サイズ・個数にも差があるかを区別します。
原因がまだ未確定のため、不一致時に上書きを止める動作は維持しています。
同じファイルを処理し、失敗後に「ログをすべてコピー」からログを送ってください。

【v1.3.2 添付フォント名のパス省略に対応】
添付名が「fonts\01\font.ttf」から「font.ttf」へ変わる場合に、
不一致として停止していた問題を修正しました。
入力側のディレクトリ部分の省略だけを許容し、ファイル名本体・MIMEタイプ・
サイズ・個数の検証は継続します。チャプターとトラックの検証も維持します。
自動テスト26件、および報告されたログの添付9個の処理前後データで確認済みです。
実際の動画ファイルを使用したWindowsでの再処理は未検証です。

【v1.4 大量読み込み時の負荷対策】
・画面更新待ちを最大256イベントに制限。超過時は読み込み側が待ちます。
・画面更新は1回64イベント／約15msを目安に分割し、操作へ制御を戻します。
・画面ログは最新2000行・最大約50万文字まで。全履歴は従来のログファイルへ保存。
  「表示中のログをコピー」は最新分、「ログを保存…」は全履歴です。
・MKV解析JSONの未使用タグ・コーデック私有データ等を保持しないよう変更。
  トラック選択と安全確認に使う情報は保持します。
・1ファイルの解析が120秒を超えた場合は停止し、そのファイルをスキップします。
  出力の再多重化処理自体には120秒の上限を設けません。
・検索中の検出件数を500件ごとに表示し、ファイル列挙中も中止を確認します。
・画面更新エラー後も更新ループを維持し、中止を要求します。
・Python例外や記録可能な致命的エラーを同じログフォルダの _errors.log へ保存。
  OSからの強制終了やメモリ枯渇などでは記録できない場合があります。
・「ログフォルダを開く」ボタンを追加。

直接のクラッシュ原因は未確定です。大量更新・メモリ増加の原因になり得る箇所を
改善した版です。一覧の全ファイル情報は引き続き保持するため、無制限の件数を
扱えることを保証するものではありません。
自動テスト30件（2万件の模擬更新待ち、未使用メタデータ削減、解析タイムアウト、
画面更新例外からの再スケジュール等）が通過。Windows実機の長時間負荷は未検証。
再発時は「ログフォルダを開く」で最新の通常ログと _errors.log を共有してください。
